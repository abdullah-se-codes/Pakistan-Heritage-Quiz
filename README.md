## ✨ Key Features

- 📚 **Comprehensive 600-Question Verified Repository**:
  - Divided into 6 core domains with 100 deep-dive questions each.
  - Every single question contains **detailed explanations** for both correct answers and distractors, accompanied by a verified **Historical Fun Fact**.
- 🎯 **Sequential & Non-Repeating Progression**:
  - 10-question structured rounds per session.
  - Smart deduplication engine ensures you progress through all 100 questions of a topic across 10 sequential rounds without seeing repeats.
- 💡 **Instant Feedback & Context Snippets**:
  - Clear historical hints to encourage learning.
  - Dynamic option-order shuffling to reinforce true knowledge retention over spatial memorization.
- 📖 **Interactive Heritage Study Guide**:
  - Searchable, categorized repository and timeline covering pivotal dates, founders, constitutional charters, and world records.
- 🔊 **Synthesized Web Audio Feedback**:
  - Built-in audio cues for correct/incorrect answers with a persistent mute toggle.
- 🎨 **Responsive, Accessible & Modern Design**:
  - Crafted with Tailwind CSS and Motion layout transitions.
  - High-contrast, authentic Pakistani Emerald (`#01411C`) palette, clean typography, and mobile-friendly touch targets.

## 🏛️ Knowledge Domains (600 MCQs)

| Domain | Range | Focus & Scope |
| :--- | :---: | :--- |
| **🇵🇰 Pakistan Movement** | `MCQ 501–600` | Aligarh Movement, 1906 Muslim League foundation at Dhaka, 1916 Lucknow Pact, 1929 Jinnah's 14 Points, 1930 Allahabad Address, 1940 Lahore Resolution, 1946 Cabinet Mission, 1947 Independence Act & 11 August speech. |
| **⭐ National Icons & Leaders** | `MCQ 301–400` | Quaid-e-Azam Muhammad Ali Jinnah, Madar-e-Millat Fatima Jinnah, Allama Iqbal, Liaquat Ali Khan, Abdul Sattar Edhi, Dr. Ruth Pfau, Begum Ra'ana Liaquat, and national poets & reformers. |
| **🔬 Science & Innovation** | `MCQ 401–500` | Nobel Laureate Dr. Abdus Salam, SUPARCO (Rehbar-I, Badr-1, PakSAT), surgical and IT engineering hubs, Youm-e-Takbeer (Chagai-I), and major agricultural & medical pioneers. |
| **🕌 Culture, Land & Heritage** | `MCQ 201–300` | UNESCO World Heritage Sites (Mohenjo-daro, Taxila, Rohtas Fort), Badshahi Mosque, K2 & Karakoram ranges, Ajrak, Truck Art, Qawwali, and provincial traditions. |
| **🎖️ Military Gallantry** | `MCQ 001–100` | All 11 Nishan-e-Haider recipients (Raja Muhammad Sarwar to Lalak Jan), 1965 war air aces (MM Alam), Operation Swift Retort, naval operations, and border defense history. |
| **🏆 Sports & World Feats** | `MCQ 101–200` | 1992 Cricket World Cup, 2009 T20 World Cup, Jahangir Khan & Jansher Khan squash dominance, 4x Hockey World Cups, Olympic Gold feats (Arshad Nadeem), and mountaineering records. |

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm, yarn, or pnpm

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/pakistan-heritage-quiz.git
   cd pakistan-heritage-quiz
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview production build:**
   ```bash
   npm run preview
   ```
